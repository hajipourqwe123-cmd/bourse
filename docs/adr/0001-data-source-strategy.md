# ADR-0001: راهبرد منبع داده

- وضعیت: **پذیرفته‌شده به‌صورت پیش‌فرض** (تا تصمیم مالک محصول درباره قرارداد)
- تاریخ: ۱ مهر ۱۴۰۵

## زمینه
پرسش باز PRD: شروع با وب‌سرویس تجاری یا انتظار برای قرارداد رسمی TSETMC. انتظار، کل فاز ۱ را متوقف می‌کند.

## تصمیم
همه منابع پشت رابط `source.Source` قرار می‌گیرند و قرارداد داده (`model.Snapshot`) مستقل از منبع است. فاز ۱ با وب‌سرویس تجاری (سورس‌آرنا) شروع می‌شود؛ هم‌زمان مذاکره قرارداد رسمی TSETMC آغاز می‌شود. خروجی collector هر روز ضبط می‌شود تا بازپخش و مقایسه منابع ممکن باشد.

## پیامدها
- تعویض منبع = نوشتن یک آداپتور جدید؛ موتور و رابط تغییر نمی‌کنند.
- پیش از نمایش عمومی، شرایط باز‌توزیع کتبی از تأمین‌کننده لازم است (PRD بخش ۱۳).
- منبع دوم برای تطبیق متقابل در اسپرینت ۴ اضافه می‌شود.
